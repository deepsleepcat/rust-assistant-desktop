# 铁锈助手 · 电脑版（Rust Assistant Desktop）

面向《铁锈战争》（Rusted Warfare）模组开发的 **Windows 桌面工作台**：
用代码编辑器的体验写模组 ini 代码，并集成模组检查、地图预览、云仓库与社区协作。

## 特色

- **可调工作台**：左侧项目/文件树 · 主编辑区多标签编辑器；分隔条可拖拽调整，面板可折叠，窄窗口自动切换抽屉模式，文件树支持键盘导航
- **仪表盘**：连接社区服务器后显示真实余额与用量（请求量、Token 与覆盖率）；离线或数据不可用时不展示占位值
- **模组专用编辑器**（CodeMirror 6）：ini 高亮、自动补全（含 `@type`/`@customType`/`${变量}` 联想与图片预览）、智能换行、节大纲、折叠、格式化、中英翻译、lint 实时检查
- **模组工具**：新建 / 导入 / 打包 `.rwmod`、新建单位、单位检查、全局查找替换、优化清理、值类型管理（自定义补全规则）；**一键验证**——打包后自动部署到游戏 `mods/units` 目录并启动游戏（同名模组先询问是否覆盖）
- **参考库**：代码表查字段用途（支持旧名别名搜索，如 `turretlimitingAngle` → `limitingAngle`）、单位库参考官方单位（全部带中文名与描述）、炮塔可视化编辑器
- **游戏集成**：自动检测铁锈战争安装目录，一键导入官方单位示例模组、导入游戏内已装模组、启动游戏与运行前检查
- **版本差异对比**：两个游戏版本之间字段新增/弃用/改版替代一览 + 项目升级改动清单导出（官方废弃字段已全量标记：turretSize、action_#_*、动画旧键等）
- **知识包更新器**：官方数据可检测更新、增量下载、sha256 校验，失败自动保留旧版、可回滚；支持多数据源与离线兜底
- **模组关系图**：单位 → 图片/音效/弹体/炮塔引用可视化，悬空/跨模组引用一目了然，点击跳转
- **自定义检查规则**：项目 `rules/*.json` 声明式规则可试运行并保存为项目规则（不执行脚本）
- **声明式插件**：设置 → 插件 导入插件目录（manifest.json 声明翻译、字段别名、枚举解释、检查规则与渲染适配）；只支持声明式数据，不执行任何脚本，单个插件数据异常只影响自身
- **单位预览（引擎渲染）**：内置《铁锈战争》引擎渲染所需的全部组件，单位预览的画面由引擎渲染产生，与游戏里一致。引擎 DLC 安装到指定目录并授权后即可使用；未安装或未授权可用 DLC 时，不支持单位渲染（不回退到本地合成）。协议见 [ENGINE-DLC.md](ENGINE-DLC.md)
- **模板库管理**：本地浏览/分类/导入/删除模板（内置 + 用户目录，不做在线市场）
- **Git 历史与回滚**：本地 git 历史/分支可视化、冲突预览与「选择 A/B」解决、单文件回滚（仅本地单人，无服务器）
- **地图双向桥接与真实预览**：TMX 规范化导出（图层/对象/图块集 round-trip 不丢数据，Tiled 可打开）；正交有限地图按真实 tileset 渲染（内嵌 PNG、内嵌图片、外部 TSX），支持多图块集、Tiled 翻转、缩放/拖拽与超大地图安全总览；缺资源局部降级，不再整图空白
- **社区板块**：左侧「社区」入口进入独立工作区，推荐 / 关注 / 排行 / 我的四页签；启动即登录（社区账号 + 设备配对授权，令牌只存本机系统安全存储），邮箱验证后可发帖、评论、点赞、关注，以及模组附件上传与下载；服务器不可用或暂不想登录时可选**离线使用**，本地编辑不受影响。社区服务由独立的闭源后端提供，桌面端通过配置的社区接口访问
- **云仓库（云书包）**：GitHub 风格仓库页，文件 / Issues / 版本与发布 / 成员 / 设置；支持整套仓库或单个模组下载、本地项目自动同步、Release 发布与限时分享链接、Issues 与 Star
- **自动更新**：一键检查更新，更新包托管在 GitHub Releases（免费）
- 浅色 / 深色 / 跟随系统主题、自定义背景（可拖动/缩放取景，不修改原图）、鼠标粒子特效、命令面板（Ctrl+K）、可自定义快捷键、文件树排序、隐藏文件开关与**项目内全局文件搜索**、中文路径与 UTF-8 BOM 支持

## 快速开始

要求：Windows 10/11、Node.js 20+

```bash
npm install        # 安装依赖
npm run dev        # 桌面开发模式（自动编译主进程 + 热更新）
npm run dev:web    # 纯浏览器预览 http://localhost:5173（Mock 数据，无需 Electron）
```

社区功能需要可访问的社区服务地址；桌面端不会包含社区后端源码。开发环境可通过 `VITE_COMMUNITY_ENDPOINT` 配置接口地址，生产环境请使用受信任的社区服务部署。

生产构建与打包：

```bash
npm run build      # 构建渲染进程 + 主进程
npm start          # 以生产模式启动
npm run pack       # 打包安装版 + 便携版 exe → release/（electron-builder）
```

> 社区账号会话保存在本机系统安全存储中，不写入明文配置文件。

## 质量检查

```bash
npm run check      # 类型检查 + ESLint + 1370+ 个单元测试，一键全跑
```

## 手机端

基于 Tauri Mobile 的 Android 客户端源码位于 [`mobile/`](mobile/)，包含模组编辑器、AI 对话、导入导出及打包功能。开发和 Android 构建步骤见 [手机端说明](mobile/README.md)，模块划分见 [手机端架构文档](mobile/docs/ARCHITECTURE.md)。

桌面端与手机端分别安装依赖、运行检查和构建；手机端源码不进入 Electron 安装包。桌面端 `npm run check` 检查桌面工程，手机端检查从仓库根目录运行：

```bash
npm --prefix mobile ci
npm --prefix mobile run check
npm --prefix mobile run build
```

社区后端是独立的闭源服务，不随本桌面端仓库发布；本仓库只包含桌面客户端及其公开接口适配层。

## 自定义检查规则（声明式插件，M19/M21）

高级用户可在项目根目录放 `rules/*.json` 规则文件，语义检查（编辑器波浪线、质量报告）自动加载生效；检查用例可一键「试运行 / 保存为项目规则」写入 `rules/ai-rules.json`。设置 → 编辑器 里可单独开关每条规则。

**安全边界**：规则文件**只支持声明式描述，不提供任何脚本执行环境**——规则只能做「键值匹配 + 数值/枚举/正则/必需键」校验，无法执行任意代码，恶意规则最多产生误报，不能读写文件或执行命令。

规则文件格式（`formatVersion: 1`）：

```json
{
  "formatVersion": 1,
  "name": "我的规则集",
  "rules": [
    {
      "id": "maxHp-range",
      "title": "血量范围",
      "description": "maxHp 必须在 1~10000",
      "section": "core",
      "key": "maxHp",
      "severity": "warning",
      "check": { "type": "numeric-range", "min": 1, "max": 10000 }
    }
  ]
}
```

- `id`：1-64 位字母/数字/下划线/连字符，集内唯一；`title` 必填；`section`/`key` 省略 = 任意节/任意键（支持中文键名与中文节名）
- `severity`：`error` / `warning` / `info`，默认 `warning`
- `check.type` 一览：
  - `numeric-range`：数值区间 `{ min?, max? }`（至少一侧；非数字值跳过）
  - `required-key`：节内必须存在该键（需 `section` + `key`）
  - `forbidden-value`：值不得等于 `values` 任一（大小写不敏感）
  - `enum-value`：值必须是 `values` 之一（大小写不敏感）
  - `regex-match`：值必须完整匹配 `pattern`

格式错误（非法 id / 重复 / 越界区间 / 非法正则可编译等）会在设置页给出中文错误提示，坏文件只影响自身、不影响其它规则文件。
